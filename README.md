# 斜め分割サムネメーカー

複数の画像を1枚のサムネ画像にまとめる、HTML単体で動くツールです。区切り線を斜めにしたり、位置を自由に動かしたり、自動で配置したりできます。ビルド不要・外部ライブラリなしで、`thumb-maker.html` をブラウザで開くだけで使えます。

## 使い方

1. 「画像を追加」を押すか、画像をドロップします（2枚以上推奨）。
2. 「自動配置」でレイアウトを作ります。パターンは選べます。
3. キャンバス上の丸いハンドルをドラッグして、区切り線を調整します。
4. 各セルの画像を、位置・ズーム・回転で調整します。
5. 「保存する」で PNG / JPG に書き出します。

## 操作一覧

| 操作 | 内容 |
| --- | --- |
| 丸いハンドルをドラッグ | 区切り線の位置を動かす／傾ける（両端を別々に動かせる） |
| セル内をドラッグ | 画像の位置調整 |
| ホイール | 画像のズーム（100%〜400%） |
| Shift + ホイール | 画像の回転（1目盛り5°） |
| 2本指（スマホ） | ピンチでズーム、ひねりで回転 |
| 回転スライダー | 0°・±90°・±180° の近くで吸着 |
| ⟲90° / ⟳90° | 90°ずつ回転 |
| サムネ一覧の ◀ ▶ ✕ | 画像の並び替え・削除 |

## 機能

- キャンバス比率: 1:1 / 4:3 / 3:4 / 16:9 / 9:16 / 2:1、px の自由指定（100〜4000）
- 自動配置パターン: ランダム / 均等グリッド / 大1枚＋小 / 縦ストライプ / 横ストライプ
- 縦区切り・横区切りの傾きスライダー、区切りの太さ、背景（区切り）色
- 書き出し時はハンドルと選択枠を含めない

## 内部の仕組み（改造する人向け）

### レイアウトのデータ構造

```
L = {
  B:    [{l, r}, ...],   // 行の境界線。l は左端、r は右端の高さ（0〜1）。先頭は{0,0}、末尾は{1,1}
  rows: [ [{t, b}, ...], ... ]  // 行ごとの縦区切り。t は上側、b は下側の x 位置（0〜1）
}
```

- 画像は「行」に分かれ、各行が縦の区切り線で列に分かれます。
- 区切り線は端点2つで決まるので、自由に傾けられます。
- セルは4頂点のポリゴンです（`polys()`）。描画はクリップして画像を貼ります。
- ハンドルは `handles()` が返し、ドラッグで `mv()` が値を更新します。隣の線を越えないよう clamp しています。

### 画像のはめ込み（回転対応）

- 各画像は `{img, s, ox, oy, r}`（ズーム・位置・回転角[度]）を持ちます。
- 回転しても隙間が出ないよう、セルの外接矩形を回転角で射影した大きさを基準にカバースケールを計算します（`draw()`）。
- 位置のずらし量は、画像座標系に変換して「画像からはみ出さない範囲」に制限します。

### 保存

- 公開ページ（claude.ai のアーティファクト）では `downloads` 機能で保存します。
- ローカルで開いた場合は、通常の `a[download]` で保存します。
